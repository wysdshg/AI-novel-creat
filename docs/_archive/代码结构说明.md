> 与代码逐一核对（2026-08-14）。分四部分：① 后端入口与核心 ② 后端 Router（端点）③ 后端 Service（业务函数）④ 前端。函数均列出真实签名与职责，括号内是主要调用方。

## 一、后端入口与核心（backend/）

### `backend/dev.py`
开发启动入口。`__main__` 里读环境变量 `DEV_RELOAD`（默认 `"0"` 关 reload）、`HOST`（默认 `127.0.0.1`）、`PORT`（默认 `8000`），调 `uvicorn.run("main:app", ...)`。启动时 `main.py` 的 startup 钩子会 `init_db()`。
- **调用方**：`start_project.ps1` / 手动 `python dev.py`。

### `backend/main.py`
FastAPI 应用入口。
- 创建 `app = FastAPI(...)`，挂 CORS（`allow_origins=["*"]`）。
- 统一把 17 个 router 以 `prefix="/api/v1"` 注册（projects/database/chapter/discussion/model/memory/foreshadow/direction/template/references/setting/custom_skill/workflow/volume/article/reference_global/assist）。
- `@app.on_event("startup")` → `init_db()` + 幂等安装预置写作 SKILL（`seed_skills.install`，异常不阻断启动）。
- 系统端点：`GET /api/v1/health`（探针）、`GET /`（说明）。

### `app/core/config.py`
常量：`BASE_DIR`、`DEFAULT_DB_URL`（`~/.ai_novel/data/novel_agent.db`）、`DB_BACKEND`、`TEMPERATURE_PRESETS`、`CHAPTER_WORD_MIN/MAX`（3000/5000）。

### `app/core/response.py` — 统一信封
- `_trace()` → 生成 `trace_id`。
- `ok(data, message="success")` → `{code:0, message, data, trace_id}`。
- `fail(code, message, data=None)`、`not_implemented(feature)` → 50101。
- `paginated(items, total, page, page_size)` → 分页包装。
- **调用方**：几乎所有 router 端点。

### `app/core/database.py` — 引擎/会话/迁移
- `get_engine()`：惰性创建 engine；SQLite 时自动建父目录 + `check_same_thread=False`；首次调用赋值模块级 `SessionLocal`（⚠️ 必须运行时属性访问，import 时仍是 `None`）。
- `get_session()`：FastAPI 依赖，请求级 session，finally 关闭。
- `_auto_migrate(engine)`：比对 ORM 与已有表，缺列自动 `ALTER TABLE ADD COLUMN`（仅新增列场景）。
- `init_db()`：`create_all` + `_auto_migrate`，幂等。启动时调用。

### `app/core/context/` — 上下文引擎（AI 提示词组装核心）

#### `budget.py` — 上下文预算裁剪
- `class Block`：上下文块（key/title/content/priority/order/min_chars/required）。
- `class BudgetPlan`：按预算等级与优先级规划结果，`render()` 输出文本。
- `_truncate_at_boundary(text, limit)`：在边界截断。
- `plan_budget(blocks, level)`：核心调度——按优先级排序、逐块累计、超预算裁剪；`required` 块永不裁。
- **调用方**：`builder.build_chapter_messages` / `build_discussion_system`。

#### `layers.py` — 各层取数（每层返回一个 Block）
- `_safe(fn, default=None)`：包一层 try，失败返回 default（单层失败不拖垮整段组装）。
- `_relevance(text, query)`：轻量相关性（关键词重叠）。
- `extract_mentions(db, project_id, *texts)`：从文本里抽出现的角色/势力/地点名（供聚焦注入）。
- `layer_world(db, project_id, volume_id, article_id, mode, query_text)`：L1 世界观（小说概况 + 卷/篇概要 + 设定库）。内部调 `build_setting_catalog` 生成设定目录。
- `build_setting_catalog(db, project_id)`：把小说绑定的设定（`SettingORM`）渲染成目录文本（B 方案：目录 + LOAD_SETTING 按需拉正文）。
- `_render_character_full` / `_render_character_brief`：角色全量/精简渲染。
- `layer_characters(db, project_id, focus_names)`：L2 角色层；有 focus 时全量注入命中的，其余精简。
- `layer_entities(db, project_id, focus, mode, query_text)`：势力/地点/关系层。
- `layer_foreshadows(db, project_id, trigger_ids, mode, query_text)`：伏笔层；`mode="relevant"` 按相关性裁剪 pending 伏笔，作者指定 `trigger_ids` 永远保留。
- `layer_prev_chapter(db, project_id, chapter_no)`：L5 上一章结尾。
- `layer_recent_memories(db, project_id, chapter_no, limit)`：L4 最近 N 章记忆。
- `layer_stage_summaries(db, project_id, chapter_no)`：L3 阶段摘要。
- `layer_discussion(db, project_id, chapter_id, conversation_id)`：L0 最近商讨（对话进入商讨上下文）。
- **调用方**：`builder`。

#### `builder.py` — 组装 messages（总调度）
- `is_advice_request(text)`：判断是否咨询/建议类请求（影响商讨分支）。
- `_mk(key, title, content, priority, order, min_chars)`：构造 Block。
- `_resolve_level(db, override)` / `_resolve_layer_mode(override)`：预算等级 / 裁剪模式解析。
- `build_chapter_messages(db, project_id, *, chapter_no, article_id, volume_id, prompt_hint, word_range, trigger_foreshadow_ids, from_discussion, budget_level, layer_mode, chapter_id, conversation_id)` → `(messages, meta)`：**章节生成核心**。
  1. 取商讨块 + `extract_mentions` 识别实体；
  2. 逐层 `_add(layer_*)`：discussion→world→characters→entities→foreshadows→stage_summaries→recent_memories→prev_chapter；
  3. `reference_crud.pick_relevant` 挑参考文档；
  4. 追加"本章任务"指令块（含写作纪律五条，required 永不裁剪）；
  5. `plan_budget` 裁剪 → 组装 messages。
- `build_discussion_system(db, project_id, *, chapter_id, chapter_no, article_id, budget_level, query_text)` → `(system_prompt, meta)`：**商讨系统提示词**。组装角色/实体/伏笔/阶段摘要/最近记忆层 + `skill_dispatch.build_block` 注入 SKILL。
- **调用方**：`routers/chapter.py::generate_chapter`、`routers/discussion.py::chat`。

### `app/core/gateway/` — 多厂商模型网关
- `base.py::class BaseModelAdapter(ABC)`：抽象基类，定义 `chat` / `stream` / `astream` / `test_connection`。
- `registry.py`：`register(vendor)`（装饰器注册）、`get_adapter(vendor, config)`（按 vendor 取适配器，未注册回退 `PlaceholderAdapter`）。
- `adapters/openai_compat.py::class OpenAICompatibleAdapter`：`/chat/completions`，覆盖 openai/deepseek/qwen/kimi/ernie/spark/custom。
- `adapters/claude.py::class ClaudeAdapter`：`/v1/messages`，system 顶层 + SSE `content_block_delta`。
- `adapters/ollama_native.py::class OllamaNativeAdapter`：`/api/chat`；`_fit_num_ctx` 动态窗口、`repeat_penalty`、`think` 开关；**章节生成默认走此适配器**。
- **调用方**：`chapter.py` / `discussion.py` / `config_command.py` / `ingestion.py` / `assist.py` 等所有调模型处。

### `app/models/orm.py` — SQLAlchemy ORM（22 张表）
`ProjectORM` / `CharacterORM` / `SkillORM` / `RelationORM` / `FactionORM` / `LocationORM` / `ForeshadowORM` / `ChapterORM` / `VolumeORM` / `ArticleORM` / `DiscussionMessageORM` / `DiscussionLoadLogORM` / `ModelConfigORM` / `DirectionORM` / `OutlineORM` / `ReferenceDocORM` / `SettingORM`（全局）/ `CustomSkillORM`（全局）/ `WorkflowORM`（全局）/ `ChapterMemoryORM` / `StageSummaryORM` / `AppConfigORM`。
- 业务表含 `project_id` 隔离；全局三表无 `project_id`。
- `ChapterORM.article_id`、`ArticleORM.volume_id` 构成 4 级结构。

### `app/schemas/` — Pydantic 模型
每实体一个文件：`project / database / chapter / discussion(在 chapter.py 内) / model / memory / reference / setting / custom_skill / workflow / volume / article / template / common`。注意 `workflow.FlowEdge.from_` 用了 `alias="from"`（读写必须 `by_alias=True`）。

## 二、后端 Router（端点一览）

> 路径前缀统一 `/api/v1`。完整入参出参见 `API接口规范.md`。⚠️=桩。

### `routers/projects.py`
- 作品 CRUD + 分页；`GET/PUT /projects/{pid}/settings` 绑定设定库（PUT 全量替换并校验 ID）。

### `routers/database.py`
- 角色 / 技能 / 关系 / 势力 / 地点 CRUD；`geo-relations` 方位推导；`POST /validate`（⚠️桩）；`POST /command`（自然语言入库，真调 LLM）。

### `routers/volume.py` / `routers/article.py`
- 卷 CRUD；篇 CRUD + `/articles/{aid}/chapters` 列/建章。删除级联（删卷删篇删章）。

### `routers/chapter.py`
- `POST /chapters/generate`（SSE 流式生成）、`POST/GET/GET/PUT/DELETE /chapters`。
- 内部辅助函数：`_dedup_trailing_repeats`（尾部去重）、`_similarity`、`_sse`、`_content_only_stream`（只收 content 丢弃 reasoning）、`_next_chapter_no`、`_maybe_load_refs`（hybrid 模式）、`_global_topup_ids`（全局参考补位）、`_background_ingest`（后台摄取线程）、`_chapter_to_dict`。
- **调用**：`context.builder.build_chapter_messages` → `gateway` 适配器流式生成 → 落库 `chapter_crud` → 后台 `ingestion.ingest_chapter`。

### `routers/discussion.py`
- 商讨 GET/POST/DELETE/archive；`POST /discussion/chat`（SSE）；`POST /discussion/global-chat`（全局漫游）；`GET /discussion/load-logs`（P0 观测）。
- 内部：`_resolve_model`、`_strip_load_refs`（剥掉 LOAD_REFS 行）、`_collect_skill_blocks`、`_to_frontend`、`_build_entity_suggestion`（LLM 抽实体）、`_build_global_system`、`build_discussion_system`（来自 context.builder）。
- **调用**：`context.builder.build_discussion_system` → `reference_crud.build_catalog/format_catalog_prompt`（目录+协议）→ gateway 流式 → `discussion_crud.add_message` 落库。

### `routers/memory.py`
- 摄取/章记忆 CRUD/阶段压缩/总览/大事记/待确认实体；全部走 `ingestion` + `memory_crud`。

### `routers/model.py`
- 模型 CRUD + set-default + test（真实请求厂商）。走 `model_crud`。

### `routers/foreshadow.py` / `direction.py` / `template.py`
- 均 ⚠️桩：占位返回 + `stubs` 兜底。

### `routers/references.py` / `reference_global.py`
- 按小说参考 CRUD + catalog；全局池 CRUD + catalog + import-global。走 `reference_crud`。

### `routers/setting.py` / `custom_skill.py` / `workflow.py`
- 全局设定库 / 写作 SKILL / 工作流 CRUD。

### `routers/assist.py`
- 去 AI 味 scan / prompt；SKILL dispatch / seed；全局 config 读写；参考 recommend；`confirm-entities`（实体确认入库，重名跳过）；`llm/polish-element`（要素润色）；`aggregate-overview`（聚合概览）。内部有 `_strip_wrapper` 等。

## 三、后端 Service（业务函数）

### 作品与结构
- `project_crud.py`：`create/list/get/update/delete_project`；`_RELATED` 删除清单含 15 张业务表；`_count_chapters`。
- `volume_crud.py`：`create/list/get/update/delete_volume`（delete 级联删篇+章）。
- `article_crud.py`：`create/list/get/update/delete_article`（delete 级联删章；update 换卷校验）。

### 资料库
- `character_crud.py`：角色 CRUD（`create_character` 字段校验）。
- `faction_crud.py` / `location_crud.py` / `relation_crud.py` / `skill_crud.py`：对应 CRUD；`location_crud._bearing_text` / `geo_relations` 方位推导。

### 章节/商讨/记忆
- `chapter_crud.py`：章 CRUD。
- `discussion_crud.py`：`add_message` / `list_messages` / `clear_messages` / `archive_to_chapter` / `count_current`；线程优先级 conversation > chapter > 默认。
- `memory_crud.py`：`upsert_chapter_memory` / `get/list/delete_chapter_memory` / `set_status` / `upsert_stage_summary` / `list_stage_summaries` / `find_uncompressed_range`（够 N 章自动压缩） / `memory_to_dict` / `stage_to_dict`。
- `ingestion.py`（写后摄取核心）：`ingest_chapter(db, project_id, chapter)`（抽 plot_points/角色状态/新实体/伏笔动作/摘要 + 推走向卡片）；`parse_json_loose` / `normalize_extract` / `fallback_extract`（LLM 失败兜底）；`compress_stage`（阶段压缩）；`aggregate_overview`（递归聚合篇/卷概览）；`_render_directions`（走向卡片文本）。
- `model_crud.py`：模型 CRUD + `set_default` / `get_default` / `test_connection`（真实请求）。

### 参考与设定
- `reference_crud.py`：`list/create/get/update/delete_reference`；`auto_summary` / `auto_tags`；`build_catalog`（目录，按 article_id 过滤，locked 置顶）；`format_catalog_prompt`（目录渲染 + 加载协议说明）；`parse_load_refs` / `parse_load_setting`（解析 AI 的加载指令）；`fetch_refs_by_ids` / `fetch_settings_by_ids`（按 id 取正文）；`import_global_references`（复制全局→小说）；`append_article_digest` / `upsert_article_reference`（篇章摘要落库）；`score_reference`（相关性打分）；`pick_relevant`（章节选参，默认 top）；`recommend_global_references`。
- `reference_selector.py`：`class ReferenceSelection` / `MarkerSelection` / `ToolCallSelection`；`get_reference_selector(mode)` 工厂，`os_environ_mode()` 读 `NA_REF_SELECTOR`。
- `setting_crud.py`：全局设定 CRUD。
- `custom_skill_crud.py`：全局 SKILL CRUD。
- `skill_dispatch.py`：`collect(db, trigger)`（按 trigger 取启用 SKILL，互斥分类只留 priority 最高，叠加类全留）；`build_block(db, trigger)`（渲染成提示词块）；`explain`。
- `seed_skills.py::install(db, overwrite)`：幂等安装预置 6 条 SKILL。

### 调度 / 辅助
- `config_command.py`：`run(db, project_id, text, dry_run, model_id, entity_type)`（自然语言→结构化→upsert；可限定单类实体）；`_extract_json` / `_sanitize_characters`（字段纠错） / `_apply`（落库）。
- `humanizer.py`（去 AI 味）：`scan(text, scene)`（主入口，多扫描器组合打分）；内部 `_scan_patterns / _scan_words / _scan_cliche / _scan_adverb_stacking / _scan_english_mix / _scan_no_punct_run`；`_grade`（分级）；`build_prompt_block`（前置注入提示词）；`quick_stats`。词表在 `core/banned_words.py`。
- `load_observation.py`：`record(...)`（P0 观测落库：实际加载了哪些设定/参考）；`list_logs`。
- `app_config.py`：`get` / `set_value` / `get_all` / `set_many` / `describe`；常量 `KEY_RECENT_MEMORY_N` / `KEY_HUMANIZE_SCAN` / `KEY_INGEST_ENABLED`。
- `stubs.py`（仅桩模块兜底）：`validate_settings` / `list_templates` / `generate_outline` / `recommend_directions` / `list/detect/get_active_foreshadows` 等，均返回假数据。

## 四、前端（frontend/src）

### `api/` — 统一请求层
- `http.js`：axios 实例，baseURL `/api/v1`，timeout 180s；**响应拦截器自动解包信封 `data`**（code≠0 自动 `ElMessage.error`）。
- `projects.js / database.js / volume.js / article.js / chapter.js / discussion.js / model.js / memory.js / reference.js / setting.js / customSkill.js / workflow.js / direction.js / foreshadow.js / template.js / assist.js`：各模块 API。`discussion.js` 含 SSE 流解析（`discussionChatStream` / `discussionGlobalChatStream`）。

### `store/project.js` — Pinia 全局状态（唯一 store）
**state**：`novels / models / currentNovelId / currentChapterId / currentModelId / structure{volumes} / structureLoaded / discussionMessages / sendingDiscussion / conversations / currentConversationId / loaded`。
**getters**：`currentNovel / currentVolume / currentArticle / currentChapter / currentModel / currentConversation`。
**actions**：
- `loadNovels` / `addNovel` / `selectNovel`（选小说：重置结构 + 建会话线程 + 载讨论）。
- `loadModels` / `selectModel(id)`（切模型）。
- `resetStructureState` / `loadStructure(projectId)`（拉卷→篇→章）。
- `selectVolume / selectArticle / selectChapter`（导航，selectChapter 补全父卷/篇 + 切章线程）。
- `deleteNovel`（删小说；若删当前，重置会话/章节/消息状态）。
- `clearDiscussion` / `appendPersistedMessage`（落库本地消息）/ `sendDiscussion`（核心：全局漫游 or 小说商讨，SSE 流式；自动建会话线程）。
- `loadDiscussion`（线程优先级读历史）。
- 会话管理：`hydrateConversations / addConversation / selectConversation / ensureConversation / removeConversation`（删除会话时按会话自身 novelId 同步清后端消息）。
- `_saveActiveToStorage` / `_loadConversationsFromStorage` 等 localStorage 持久化。

### `router/index.js`
`/workspace` 布局 + 子路由；`meta.tab`（parent/sub）驱动 MainLayout 顶部标签自动渲染；`hideTopNav` / `hideTab` 控制显隐。

### `layout/MainLayout.vue`
侧栏（作品树 + 会话列表 + 入口）+ 顶部 tab + 主内容区；删除作品/会话确认弹窗；logo 点击回首页。

### `views/`（业务页面）
`ChatView`（对话+生成入口，核心）/ `OverviewView` / `DatabaseView`（角色）/ `SkillListView`（技能）/ `FactionView` / `LocationView` / `WorldMapView` / `CharacterRelationView` / `ConfigChatView` / `ReferenceView` / `GlobalReferenceView` / `SettingView` / `CustomSkillView` / `WorkflowView` / `ModelConfigView` / `ChapterListView`；`ForeshadowView / DirectionView / TemplateView` 为占位 UI；`_deprecated/` 下 `ChapterView.vue / DiscussionView.vue` 已废弃。

### `components/`（核心组件）
- `workspace/ChatInput.vue`：底部输入框（`@角色/@势力` 快捷输入、模型选择）。
- `workspace/ChatPanel.vue`：消息渲染（含走向卡片/实体确认卡片）。
- `workspace/GenerateChapterDialog.vue`：章节生成对话框（SSE 事件处理：thinking/chunk/context/validate/stopped/ingest_start/saved/done；生成后刷新结构并 `selectChapter`）。
- `workspace/ChapterElementsForm.vue` / `ChapterElementsPanel.vue`：章节要素表单/面板。
- `workspace/CreateNovelDialog.vue` / `NameGeneratorDialog.vue`：新建小说/取名。
- `database/CharacterForm.vue` / `FactionForm.vue` / `LocationForm.vue`、`character/CharacterForm.vue`：资料库表单。
- `relation/RelationGraph.vue`：关系网可视化。
- `foreshadow/ForeshadowTimeline.vue`、`template/TemplateDialog.vue`。

### `utils/`
- `nameGen.js`（随机取名）、`slash.js`（`/` 指令解析）、`templateParser.js`（模板解析）。
